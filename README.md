# Ruby Market Tracker

아이템매니아와 카카오톡 오픈채팅 대화 내보내기 txt에서 루비 시세를 수집해 Google Sheets `루비 시세 DB`에 기록하는 프로젝트입니다.

## 시트 컬럼

A 날짜  
B 수집 시간  
C 아이템매니아 최저  
D 아이템매니아 평균  
E 아이템매니아 매물수  
F 오픈톡 평균  
G 오픈톡 최저  
H 오픈톡 최고  
I 오픈톡 거래글수  
J 비고  
K 특이사항  

## 실행

```bash
pip install -r requirements.txt
python main.py
